# BIS Sahayak — Code Surfers

## Smart Digital Assistant for BIS Standards & Certification

BIS Sahayak is a smart web-based platform designed to help users understand BIS standards, certification procedures, testing requirements, hallmarking, laboratories, and consumer-related information through an easy-to-use interface.

## Key Features

- 🤖 BIS AI Assistant
- 🔎 Smart Standard Finder
- 📋 Certification Guidance
- 🛣️ Certification Roadmap
- 🧪 Testing Requirements & Guidance
- 🏭 Laboratory Finder
- 💎 Hallmarking Assistant
- 🛡️ Consumer Support
- 📊 Compliance Dashboard
- 📄 Documentation & Gap Analysis
- 🌐 Multilingual Support
- 📚 Source & Evidence References

## Technology Stack

- **Frontend:** React + TypeScript
- **Build Tool:** Vite
- **Backend:** TypeScript / Node.js
- **AI Layer:** Gemini API
- **Database:** Drizzle ORM
- **Authentication:** Firebase Authentication
- **Styling:** CSS
- **Version Control:** Git & GitHub
